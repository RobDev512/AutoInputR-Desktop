# Identidad visual de TaskPilot

La identidad visual de TaskPilot utiliza azul profundo, cian eléctrico y blanco sobre una estética tecnológica oscura. El símbolo combina una ventana de escritorio, una ruta con nodos y un cursor para representar automatización visual guiada.

## Recursos

| Archivo | Uso recomendado |
| --- | --- |
| `TaskPilotLogo.png` | Logo principal con fondo oscuro; portadas, documentación y presentación |
| `TaskPilotLogoHorizontal.png` | Lockup horizontal transparente; headers y Hub |
| `TaskPilotIcon.png` | Símbolo transparente; aplicación, bandeja y usos compactos |
| `TaskPilotLogoTransparent.png` | Logo apilado transparente; fondos personalizados |
| `TaskPilotMono.png` | Versión monocromática; documentación y usos de un solo color |
| `TaskPilotIcon.ico` | Ejecutable, instalador y accesos directos de Windows |

## Nombre

La marca se escribe **TaskPilot**, sin espacio y con `T` y `P` mayúsculas.

## Etapa histórica

Los recursos `LogoAIR`, `Logo2AIR` y el nombre AutoInputR corresponden a la identidad anterior usada hasta v1.3.0. No deben reutilizarse en interfaces nuevas de TaskPilot, salvo en documentación histórica.
